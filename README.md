# Web Scraper

Bu proje, CTI kapsamında Go dili kullanılarak geliştirilmiş basit bir web scraper uygulamasıdır.

## Özellikler
- Komut satırından hedef URL alma
- Web sayfasının HTML içeriğini dosyaya kaydetme
- Web sayfasının ekran görüntüsünü alma
- HTTP hata kontrolleri

## Gereksinimler
- Go (Golang)
- Google Chrome (chromedp için)

## Kullanım
```bash
go run main.go https://www.example.com
